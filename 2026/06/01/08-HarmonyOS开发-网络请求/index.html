网络请求

基本概念

网络通信通常由客户端和服务端组成, 客户端发起请求, 服务器返回响应

HTTP

Hyper Text Transfer Protocol, HTTP(超文本传输协议)是一种用于客户端与服务端之间传输超文本数据的应用层通信协议, 规定了双方的通信格式和交流逻辑.

HTTP发送请求的完整流程:

  1. 客户端与服务端建立连接, 建立稳定的通信通道
  2. 客户端通过这个通道向服务端发送具体的请求内容
  3. 服务端处理完网络请求后通过网络协议发送客户端能够识别的响应报文对应的内容并进行处理
  4. 如果双方不需要连接就关闭连接

URL

URL是用来定位服务端资源的唯一地址

例如: `https://developer.huawei.com/consumer/cn/doc/

其中

  • https: 协议类型, 告诉客户端和服务端要用HTTP协议的加密版本通信
  • developer.huawei.com: 域名, 相当于服务端的”地址”, 找到对应的服务器
  • consumer: 资源路径, 告诉服务端要访问上面的相关文档资源

请求报文

客户端发送给服务端的”请求内容”, 有固定的格式, 包含请求行和请求头两部分.

第一行是请求行明确了三个信息

  1. 请求方法: GET
  2. 资源路径: /consumer/cn/doc/
  3. 使用的协议版本: HTTP/1.1

第二行开始就是请求头信息, 每一行都是一个键值对用来告诉服务端额外信息. 比如: HOST: developer.huawei.com指定了要访问的服务端域名.

请求报文就是客户端给服务端的”结构化留言”, 既说清了要做什么(请求行), 也说明了相关要求(请求头)

HTTP方法

  1. GET方法主要用于”获取数据”, 请求参数会跟在URL后面
  2. POST方法主要用于”提交数据”, 请求参数放在请求体里, 不会显示在URL上, 相对更安全
  3. PUT方法主要用于”修改数据”
  4. DELETE方法主要用于”删除数据”

网络响应

响应报文

响应报文也有固定的格式. 包含响应行, 响应头, 响应体三个部分.

响应体是服务端返回的具体数据. 不展示.

HTTP/1.1 200 OK这就是响应行, 包含使用的HTTP版本HTTP/1.1, 响应码(200), 状态描述(OK)

从第二行开始就是响应头, 每一行都是键值对.

Content-Type: text/html; charset=UTF-8: 告诉客户端响应体的数据类型和编码方式

Content-Encoding: br: 响应体数据应用的压缩算法

Date: Fri, 12, Feb 2021 01:59:01 GMT: 服务端处理请求的时间
Server: gws: 服务器类型

常见响应码

  • 2xx: 成功, 报文已经收到且被正确处理
  • 4xx: 客户端发送的报文错误, 服务端无法处理
  • 5xx: 服务器错误

使用http模块发起网络请求

Network kit是实现HTTP网络请求的核心工具, 是HarmonyOS提供的一套完整的网络工具箱. http模块封装了底层网络通信细节, 提供了简洁高效的接口, 使开发者能够轻松实现各种网络功能专注于业务逻辑而非网络协议的实现.

核心接口

  • createHttp(): 负责创建一个具体的HTTP请求任务也就是HttpRequest对象, 用于调用常用的网络请求方法, 是后续所有HTTP操作的基础, 可以通过request()方法发起请求, destory()方法销毁请求, on()方法和off()方法完成事件的订阅和取消.

    1. httpRequest.request()

      request(url: string, options?: HttpRequestOptions): Promise<HttpResponse>;

HTTP流式传输是指在处理HTTP响应时，可以一次只处理响应内容的一小部分，而不是一次性将整个响应加载到内存，这对于处理大文件、实时数据流等场景非常有用。

通过HTTP发起WebDAV请求

从API version 23开始，HTTP请求支持WebDAV协议的文件访问，WebDAV是基于HTTP协议的扩展，支持对远程服务器上的文件进行创建、读取、更新、删除、移动、复制(MKCOL、GET、PUT、DELETE、MOVE、COPY)等操作。
